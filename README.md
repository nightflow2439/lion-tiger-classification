# 狮子老虎图片分类（Lion vs Tiger Classification）

基于**自实现的 SMO（序列最小优化）算法**训练线性 SVM，对狮子与老虎图片进行二分类。不依赖 sklearn 等机器学习库的 SVM 实现，SMO 全程手写。

## 项目结构

```
lion_tiger_classification/
├── lion_tiger_classification.ipynb   # 主代码：数据加载、SMO 训练、10 轮评估
├── lion_tiger_dataset/
│   ├── Lion/                         # 狮子图片 230 张（lion_001.jpg ~ lion_230.jpg）
│   └── tiger/                        # 老虎图片 230 张（tiger_001.jpg ~ tiger_230.jpg）
└── README.md
```

## 数据集

- 共 **460 张**图片：狮子 230 张、老虎 230 张
- 预处理：统一转为灰度图（`convert("L")`），尺寸 224×224（50176 像素），像素值归一化到 [0, 1]
- 标签：狮子 = **1**，老虎 = **-1**

## 方法

1. **特征表示**：将每张灰度图的像素矩阵展平为一维向量并归一化，作为样本特征。
2. **数据划分**：随机打乱后按 **80% / 20%** 划分训练集与测试集（每轮重新划分）。
3. **模型**：线性核 SVM，使用手写的 **SMO 算法**求解对偶问题：

   - 参数：最大迭代 `maxIter=40`，容差 `toler=0.01`，惩罚系数 `C=0.6`
   - 通过拉格朗日对偶将原问题转化为关于 α 的二次规划，SMO 每次选取两个变量优化并裁剪到合法区间 `[L, H]`
   - 决策函数：`f(x) = sign(w·x + b)`，其中 `w = Σ αᵢ yᵢ xᵢ`

4. **评估**：独立运行 **10 轮**随机划分训练，统计平均准确率。

## 结果

| 指标 | 10 轮平均值 |
| --- | --- |
| 训练集准确率 | 99.95% |
| 测试集准确率 | 68.91% |

训练集可达到 100%，测试集约 69%，存在明显过拟合——原因在于直接使用原始像素特征（50176 维）且无正则化/特征降维，线性模型难以充分泛化。
